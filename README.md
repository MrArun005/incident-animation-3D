# incident-animation-3D

3D animated reconstructions of real incidents. Every model, texture and sound
is generated in code; there are no external assets.

| Film | Folder |
|---|---|
| US Airways Flight 1549, the "Miracle on the Hudson" (15 January 2009) | [`flight-1549/`](flight-1549/) |
| Whiteboard story #1: Flight 1549, how an airliner became a glider, narrated by a pixel critter | [`whiteboard/`](whiteboard/) |
| Whiteboard story #2: the Pythagorean theorem, proved visually, with voice-over | [`whiteboard/`](whiteboard/) |
| Clawd's Stories: How we invented farming, a narrated cartoon | [`cartoons/`](cartoons/) |
| An orange "thinking" spark emoji (looping transparent GIF, 128/256/512 px) | [`spark-emoji/`](spark-emoji/) |
| The orange pixel critter running (emoji GIFs: in place 128/512 px, and back-and-forth) | [`critter-emoji/`](critter-emoji/) |
